# Bubble Shooter

Et Bubble Shooter-spill utviklet i Java som individuelt prosjekt i INF101 Programmering 2 ved Universitetet i Bergen.

Spillet har et grafisk grensesnitt laget med Java Swing. Spilleren sikter med musen og skyter bobler mot spillbrettet. Prosjektet er strukturert med separate klasser for spillmodell, visning og kontroller.

## Funksjoner
- Sikting og skyting med mus

- Beregning av boblenes bevegelse og kollisjoner

- Spillbrett med rutenett og poengsum

- Startskjerm, spillslutt og mulighet for å starte på nytt

## Kontroller

- Mellomrom: Start spillet fra startskjermen

- Mus: Sikt og klikk for å skyte

- R: Start på nytt etter spillslutt

- H: Gå tilbake til startskjermen etter spillslutt

## Teknologi

Java, Java Swing, Maven og JUnit.

## Slik starter du spillet

Åpne prosjektmappen i VS Code med Java-utvidelsene installert. Prosjektet krever Java 17 eller nyere. Åpne src/main/java/app/Main.java og velg Run over main-metoden.
